# Meu Portal de Entretenimento Digital

Este projeto foi desenvolvido como atividade prática de HTML e CSS.

O objetivo foi criar uma página web temática sobre entretenimento digital, utilizando diferentes formas de CSS e organização com Flexbox.

## Conteúdo da Página

A página possui três seções principais:

- Filmes e Séries
- Música e Podcasts
- Games e Tecnologia

Cada seção contém:
- títulos
- imagens ilustrativas
- textos explicativos

## Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Reset

## Recursos Aplicados

- CSS Inline
- CSS Interno
- CSS Externo
- Classes e IDs
- Layout Responsivo
- Flexbox
